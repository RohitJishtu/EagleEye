# Study Resources

Curated list of books, videos, articles, and tools for mastering HLD and LLD.

---

## 📚 Books

### Must-Read

1. **"Designing Data-Intensive Applications"** by Martin Kleppmann
   - Level: Intermediate to Advanced
   - Focus: Distributed systems, databases, HLD
   - Why: Best book on modern system design
   - [Link](https://www.oreilly.com/library/view/designing-data-intensive-applications/9781491903063/)

2. **"Clean Code"** by Robert C. Martin
   - Level: Beginner to Intermediate
   - Focus: Code quality, LLD
   - Why: Foundational principles for writing good code
   - [Link](https://www.oreilly.com/library/view/clean-code-a/9780136083238/)

3. **"Design Patterns: Elements of Reusable Object-Oriented Software"** by Gang of Four
   - Level: Intermediate
   - Focus: Design patterns, LLD
   - Why: The classic reference for design patterns
   - [Link](https://www.oreilly.com/library/view/design-patterns-elements/0201633612/)

4. **"System Design Interview"** by Alex Xu (Volumes 1 & 2)
   - Level: Intermediate
   - Focus: Interview prep, HLD
   - Why: Best interview preparation resource
   - [Link](https://www.amazon.com/System-Design-Interview-insiders-Second/dp/B08CMF2CQF)

### Recommended

5. **"Building Microservices"** by Sam Newman
   - Focus: Microservices architecture
   
6. **"Domain-Driven Design"** by Eric Evans
   - Focus: Complex domain modeling

7. **"The Pragmatic Programmer"** by David Thomas & Andrew Hunt
   - Focus: General software engineering practices

8. **"Head First Design Patterns"** by Eric Freeman
   - Focus: Design patterns (easier than Gang of Four)

## 📅 Study Schedule Integration

### Weekly Reading Plan

- **Monday**: Read 1 chapter from main book
- **Tuesday**: Watch 1 video lecture
- **Wednesday**: Read 2-3 blog articles
- **Thursday**: Study open-source code (30 min)
- **Friday**: Review flashcards
- **Weekend**: Practice problems

### Resource Progression

**Week 1-2**: Clean Code + System Design Primer (GitHub)  
**Week 3-4**: Design Patterns book + Refactoring.Guru  
**Week 5-6**: Designing Data-Intensive Applications  
**Week 7-8**: System Design Interview + Mock practice

## 💡 How to Use These Resources

1. **Don't try to read everything**
   - Pick 1 book, 1 blog, 1 video series
   - Go deep, not wide initially

2. **Active Learning**
   - Take notes
   - Implement examples
   - Teach concepts to others

3. **Build Projects**
   - Apply what you learn
   - Build mini-versions of systems

4. **Join Communities**
   - Ask questions
   - Share your learnings
   - Get feedback
